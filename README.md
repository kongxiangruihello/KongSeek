# KongSeek

macOS 菜单栏文件搜索工具：随时唤出，按文件名、拼音全拼或首字母找到文件、文件夹和应用，并即时预览。
需要 macOS 13 或更高版本。KongSeek 是新写的应用，与 KongFetch 3.x、4.x 互不影响，可以同时安装。

## 安装

1. 双击 `构建并安装.command`：先运行测试，再编译、签名，把 KongSeek 装进“应用程序”并启动。
2. 首次启动会弹出搜索窗口，并在后台建立索引（菜单栏放大镜图标里可以看到进度）。
   macOS 会询问是否允许访问“文稿”“桌面”“下载”等文件夹，请选“允许”，否则这些文件夹里的文件搜不到。
3. 如果钥匙串里有名为 `KongSeek Local Signing` 或 `KongFetch Local Signing` 的代码签名证书，构建时会自动使用，
   之后每次更新都不必重新授权。

## 使用

| 操作 | 按键 |
| --- | --- |
| 打开 / 关闭搜索窗口 | ⌥空格，或连按两次 Control（都可在“设置…”中更改） |
| 切换按名称 / 按内容（全文）搜索 | ⇥ |
| 选择结果 | ↑ ↓ |
| 打开所选 | ↩，或双击（文件夹则进入浏览） |
| 进入文件夹 / 返回上一级 | → 或 ⌘↓ / ← 或 ⌘↑（输入框为空时 ⌫ 也可返回） |
| 在访达中显示 / 用默认方式打开 | ⌘↩ / ⌘O |
| 更多操作（打开方式、终端、拷贝名称、移到废纸篓…） | ⌘K |
| 快速查看 | ⌘Y |
| 移到废纸篓 / 放回 | ⌘⌫ / ⌘Z |
| 直接打开第 N 项 | ⌘1 … ⌘9 |
| 拷贝文件 / 路径 / 名称 | ⌘C / ⌥⌘C / ⇧⌘C |
| 清空输入 / 关闭窗口 | ⎋ |
| 从“最近打开”中移除（搜索框为空时） | ⌘⌫ |
| 回到原来的搜索结果（浏览文件夹时） | ⎋ |

搜索语法（与 KongFetch 3.2 相同）：

- `合同 2024`：每个词都要出现在文件名里；拼音全拼、首字母也算，如 `hetong`、`ht`、`lunyu`。
- `"年度 合同"`：短语；`-草稿`：排除；`ext:pdf,docx`、`-ext:png`：按扩展名。
- 开头写类型词：`pdf`、`文档`、`图片`、`音频`、`视频`、`文件夹`。
- 自然语言筛选：`最近一周`、`今天`、`昨天`、`大于100MB`、`标签:工作`（也可写 `#工作`）。

全文模式（⇥ 切换）用 Spotlight 的内容索引搜 PDF、Word、Pages、文本等文件的正文，同样支持上面的筛选；预览区上方显示命中处的上下文，PDF 标出页码。
扫描版 PDF 和图片里的文字 Spotlight 读不到：在“设置 › 文字识别”中添加存放扫描件的文件夹，KongSeek 会在后台用本机 Apple Vision 识别（不上传），之后全文模式也能搜到，结果标为“识别文字”。

## 网页搜索与查词

- 输入“关键词 + 空格 + 内容”直接搜网站：`hd 仁`（汉典）、`ct 学而`（中国哲学书电子化计划）、`zw 王阳明`（知网）、`db`（豆瓣读书）、
  `gs`（Google 学术）、`wk`（维基百科）、`bk`（百度百科）、`g`、`bd`、`kr`（送到 KongReview 摘录）。找不到文件时列出 Google、百度。设置 › 网页搜索 可改。
- 查词：输入 `cd 仁`，或在任何应用中选中字词按 ⌃⌥D，显示“词典”App 中已启用词典的释义。

## 压缩包与批量重命名

- 压缩包内搜索：索引中 .zip 压缩包里的文件名也能搜到（不解压，拼音、首字母同样有效）。↩ 取出并打开，预览区直接显示内容，
  ⌘C 取出后拷贝，⌥⌘C 拷贝压缩包内路径，⌘↩ 在访达中显示压缩包。可在 设置 › 索引 中关闭或立即扫描。
- 批量重命名：菜单栏图标 › 批量重命名…，或在搜索结果上 ⌘K › 批量重命名…。查找替换（可用正则）或按模板编号，先预览再改名，可撤销。

## 剪贴板历史

默认关闭。按 ⌃⌥V（或菜单栏图标 › 剪贴板历史）打开窗口，点“启用剪贴板历史”，之后复制的文字、图片和文件会被记录。

| 操作 | 按键 |
| --- | --- |
| 粘贴到原来的应用 / 纯文本粘贴 / 仅拷贝 | ↩ / ⇧↩ / ⌘↩ |
| 整理后粘贴 / 预览整理效果 | ⌘J / ⌘E |
| 固定 / 删除 | ⌘P / ⌘⌫ |
| 拷贝图片中识别出的文字 | ⌘T |
| 送到 KongReview 摘录 | ⌘R |
| 更多操作 | ⌘K |

直接粘贴需要“辅助功能”权限（设置 › 剪贴板）。带机密标记的内容（如密码管理器复制的密码）不记录。

文本片段：剪贴板窗口中按 ⇥ 切换到片段，↩ 粘贴。片段可设关键词（如 `;lk`），在任何应用中输入关键词会自动替换为片段内容
（需要“输入监控”和“辅助功能”权限）。在 设置 › 片段 中编辑。

## 其他

搜索框为空时列出最近用 KongSeek 打开过的文件和应用。命中的文字、拼音对应的汉字和缩写字母会以黄色标出。

连按 Control 需要“输入监控”权限：首次启动时系统会询问；也可以在“设置…”里点“授予‘输入监控’权限”，
在系统设置中打开 KongSeek 的开关，几秒内自动生效。

设置窗口（菜单栏图标 › 设置…）：唤起（快捷键、连按）、索引（文件夹、隐藏文件、匹配所在文件夹、登录时启动、压缩包、重建索引）、
文字识别、剪贴板、片段、网页搜索。

## 索引

- 默认索引主目录、iCloud 云盘、“应用程序”和系统应用；跳过 `~/Library`、`node_modules`、`.git`、`DerivedData`、废纸篓、
  隐藏文件和应用包内部。名为 `build`、`Library` 的普通文件夹照常收录。
- 索引存放在 `~/Library/Application Support/KongSeek/name-index.ksidx`。启动时直接载入，并从上次退出的位置补上期间的文件改动，
  不需要整盘重扫；运行时由 FSEvents 实时更新。
- 搜索引擎的速度、与 3.2 结果的一致性等测试数据见 `docs/引擎实测.md`。

## 结构

```
Sources/KongSeekCore         搜索引擎（无 AppKit，有单元测试）：名称索引、匹配与拼音、查询语法、索引文件、FSEvents
Sources/KongSeek             应用：菜单栏、全局快捷键、搜索窗口、预览
Sources/KongSeekLegacy32     KongFetch 3.2 的匹配与查询代码原样副本，只作测试和基准的对照
Sources/KongSeekTestSupport  测试与基准用的合成目录树
Sources/ksbench              性能基准：swift run -c release ksbench synth|new|legacy <目录>
Tests/                       XCTest
scripts/build-app.sh         命令行构建；--test 先跑测试，--install 安装
scripts/mac-test.sh          开发检查：编译全部目标、跑测试、可选基准，输出写入 .logs/
```
