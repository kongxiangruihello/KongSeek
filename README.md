# KongSeek

macOS 菜单栏文件搜索工具：随时唤出，按文件名、拼音全拼或首字母找到文件、文件夹和应用，并即时预览。
需要 macOS 13 或更高版本。KongSeek 是新写的应用，与 KongFetch 3.x、4.x 互不影响，可以同时安装。

## 安装

1. 双击 `构建并安装.command`：先运行测试，再编译、签名，把 KongSeek 装进“应用程序”并启动。
2. 首次启动会弹出搜索窗口，并在后台建立索引（菜单栏放大镜图标里可以看到进度）。
   macOS 会询问是否允许访问“文稿”“桌面”“下载”等文件夹，请选“允许”，否则这些文件夹里的文件搜不到。
3. 如果钥匙串里有名为 `KongSeek Local Signing` 或 `KongFetch Local Signing` 的代码签名证书，构建时会自动使用，
   之后每次更新都不必重新授权。

## 使用

窗口底部的快捷键说明也是按钮，可以直接用鼠标点击。

| 操作 | 按键 |
| --- | --- |
| 打开 / 关闭搜索窗口 | ⌥空格，或连按两次 Control（都可在“设置…”中更改） |
| 切换按名称 / 按内容（全文）搜索 | ⇥ |
| 选择结果 | ↑ ↓ |
| 打开所选 | ↩，或双击（文件夹则进入浏览） |
| 进入文件夹 / 返回上一级 | → 或 ⌘↓ / ← 或 ⌘↑（输入框为空时 ⌫ 也可返回） |
| 在访达中显示 / 用默认方式打开 | ⌘↩ / ⌘O |
| 打开到命中的那一页（PDF 在内置阅读窗口，含目录）/ 那一张幻灯片（PowerPoint） | ⌥↩ |
| 更多操作（打开方式、终端、拷贝名称、移到废纸篓…） | ⌘K，或右键单击结果 |
| 快速查看 | ⌘Y |
| 移到废纸篓 / 放回 | ⌘⌫ / ⌘Z |
| 直接打开第 N 项 | ⌘1 … ⌘9 |
| 拷贝文件 / 路径 / 名称 | ⌘C / ⌥⌘C / ⇧⌘C |
| 清空输入 / 关闭窗口 | ⎋ |
| 从“最近打开”中移除（搜索框为空时） | ⌘⌫ |
| 搜索历史（搜索框为空时） | ↑ |
| 收藏当前搜索（可命名，如课程名） | ⌘S |
| 结果按文件夹分组 / 取消 | ⌘G |
| 回到原来的搜索结果（浏览文件夹时） | ⎋ |

搜索语法（与 KongFetch 3.2 相同）：

- `合同 2024`：每个词都要出现在文件名里；拼音全拼、首字母也算，如 `hetong`、`ht`、`lunyu`。
  结果按相关度排列：完全同名最前，其次是开头命中、按音节对齐的拼音、首字母，查询占名称比例越大越靠前。
- 异体字通搜（0.20）：`峰` 也找到“峯”，`群书治要` 也找到《羣書治要》，`说文` 也找到“説文”（字表取自 OpenCC，Apache 2.0 许可）。
- 繁简通搜（0.16）：`华夏边缘` 也找到《華夏邊緣》，输入繁体 `中國` 也找到简体“中国”；全文模式、命中处摘录、识别文字同样适用。
- `"年度 合同"`：短语；`-草稿`：排除；`ext:pdf,docx`、`-ext:png`：按扩展名。
- 开头写类型词：`pdf`、`文档`、`图片`、`音频`、`视频`、`文件夹`。
- 自然语言筛选：`最近一周`、`今天`、`昨天`、`大于100MB`、`标签:工作`（也可写 `#工作`）。

高级语法（0.10 起，参照 Everything）：

| 写法 | 含义 |
| --- | --- |
| `path:讲义` / `-path:草稿` | 路径中含有 / 不含 |
| `in:~/Documents`、`in:论语` / `-in:草稿` | 在某文件夹（含子文件夹）中，按路径或文件夹名 / 排除 |
| `parent:~/Desktop`、`parent:讲义` | 直接在某文件夹中 |
| `size:>10mb`、`size:1mb..20mb`、`size:empty`、`size:large` | 按大小（1 MB = 1000 KB，与访达一致） |
| `dm:today`、`dm:thisweek`、`dm:7d`、`dm:2024-10`、`dm:>=2024-01-01`、`dm:2024-01..2024-03` | 按修改日期 |
| `dc:7d`、`dc:2024-10`（写法同 `dm:`） | 按创建日期；下载的文件即下载时间，如 `dc:7d ext:pdf` 找最近下载的 PDF |
| `regex:^第.+讲\.pdf$` / `-regex:` | 名称匹配正则（含 `/` 时匹配路径）/ 排除 |
| `file:`、`folder:` | 只要文件 / 只要文件夹 |
| `dupe:` | 只列同名文件 |

值里有空格时加引号，如 `in:"~/My Folder"`。

命令行：设置 › 通用 › 安装命令行工具 ks 后，在“终端”中输入 `ks 合同 ext:pdf`，`ks --help` 查看选项。

Claude：设置 › 通用 › “添加到 Claude 桌面版…”，重新打开 Claude 后，可以直接让 Claude 按文件名（含拼音和上面的语法）找文件，
按内容全文搜索（`search_content`），读取文件正文（`read_file`，PDF 按页），查找重复（`find_duplicates`），生成电子书参考文献（`cite_book`）。只读；正文读取可在 设置 › 通用 中关闭。
原理是 `ks mcp`（MCP 服务，只读文件名和路径）；其他支持 MCP 的应用可填命令 `/Applications/KongSeek.app/Contents/MacOS/ks`、参数 `mcp`。

搜索结果可以直接拖到微信、邮件、访达等处。

全文模式（⇥ 切换）用 Spotlight 的内容索引搜 PDF、Word、Pages、文本等文件的正文，同样支持上面的筛选；预览区上方显示命中处的上下文，PDF 标出页码，
预览区直接显示命中的那一页并以黄色标出（0.23）。
扫描版 PDF 和图片里的文字 Spotlight 读不到：在“设置 › 文字识别”中添加存放扫描件的文件夹，KongSeek 会在后台用本机 Apple Vision 识别（不上传），之后全文模式也能搜到，结果标为“识别文字”。

## 网页搜索与查词

- 输入“关键词 + 空格 + 内容”直接搜网站：`hd 仁`（汉典）、`ct 学而`（中国哲学书电子化计划）、`zw 王阳明`（知网）、`db`（豆瓣读书）、
  `gs`（Google 学术）、`wk`（维基百科）、`bk`（百度百科）、`g`、`bd`、`kr`（送到 KongReview 摘录）。找不到文件时列出 Google、百度。设置 › 网页搜索 可改。
- 查词：输入 `cd 仁`，或在任何应用中选中字词按 ⌃⌥D，显示“词典”App 中已启用词典的释义。

## 压缩包与批量重命名

- 压缩包内搜索：索引中 .zip 压缩包里的文件名也能搜到（不解压，拼音、首字母同样有效）。↩ 取出并打开，预览区直接显示内容，
  ⌘C 取出后拷贝，⌥⌘C 拷贝压缩包内路径，⌘↩ 在访达中显示压缩包。可在 设置 › 索引 中关闭或立即扫描。
- 批量重命名：菜单栏图标 › 批量重命名…，或在搜索结果上 ⌘K › 批量重命名…。查找替换（可用正则）或按模板编号，先预览再改名，可撤销。

## 整理工具（菜单栏图标）

菜单栏图标的菜单按“写作与引文”“整理文件”“书库”分组；“功能导览…”按类列出全部功能、位置和快捷键，可搜索（支持拼音首字母），点“打开”直接进入。

- 查找重复与相似文件…：完全相同的副本（逐字节核对）和同一文件的不同版本（“副本”“(1)”“_v2”、日期等），标出旧版内容有多少已包含在新版中；
  还列出同一本电子书的多个文件（PDF 与 EPUB、繁体与简体、不同网站下载的版本，按书名判断）。
- 空间分析…：最大的文件、多年未修改的大文件、占用最多的文件夹；只在 iCloud 中的文件单独计算（不占本机空间）。可直接移到废纸篓。
- 查找扫描版 PDF…：找出索引中没有文字层的 PDF，按文件夹列出页数和预计识别时间，勾选后一键加入“文字识别”在后台识别。
  也可从 设置 › 文字识别 打开。
- 已读标签：搜索结果上 ⌘K › “标为已读”，给文件加访达标签“已读”，搜索 `标签:已读` 列出全部；
  批量重命名的“电子书名称整理”可把文件名末尾的“_已读”改为标签。
- 竖排古籍识别试验：阅读窗口工具栏“识别试验”，用标准引擎（Vision）和实况文本引擎（Live Text）分别识别当前页并排对比；
  实况文本效果更好时，可在 设置 › 文字识别 中改用它做后台识别。
- 课程材料打包：收藏的搜索上 ⌘K › 打包课程材料…，或文件清单中“打包…”，复制到一个文件夹或打成 zip。
- 引文查证（菜单栏图标 › 引文查证…）：粘贴一句引文，在已建立内容索引的文件和识别过的扫描件中找出处，列出书名、页码和原文，
  标出“完全一致”或“近似 xx%”（容忍标点、空格、断行、繁简、异体和个别字的出入）；可打开到该页、拷贝出处或原文加出处。
- 选中文字直接查证（0.23）：在任何应用中选中一句引文按 ⌃⌥Q，引文查证窗口打开并查找出处（可在 设置 › 网页搜索 中更改）。
- 稿件引文核对（菜单栏图标 › 写作与引文 › 稿件引文核对…）：选一篇稿件（Word、文本、Markdown、PDF），把引号内的引文逐条到书库查证，
  列出结果、出处页码和原文，可打开到该页、拷贝出处，导出 Excel 核对表。
- 稿件参考文献表、讲义核对、通假字（0.29）：核对后一键生成所引书目的参考文献表；PowerPoint 讲义也能核对；通假、古今字（说/悦）不算错字，字表可增删。
- 常用本（0.28）：同一部书有几个版本时设一种为常用本，查证、稿件核对、出处汇编中它排在最前，拷贝出处也用它。
- 补全书目信息（0.28，搜索结果 ⌘K）：联网（Google Books、Open Library）按 ISBN 或书名查出版地、出版社、年份，核对后保存，参考文献随之补全；不改文件。
- 全文搜不到的原因（0.28）：状态与诊断中抽查各文件夹是否在 Spotlight 索引中，并说明处理办法。
- 书上页码（0.27）：出处、参考文献用书上印的页码；扫描书在结果旁点“页码…”设一次“PDF 第 N 页 = 书上第 M 页”。
- 稿件批注（0.27）：稿件引文核对后“生成带批注的 Word…”，另存一份在有问题的引文旁加批注的稿件，原稿不动。
- 出处汇编（0.27，菜单栏图标 › 写作与引文 › 出处汇编…）：把一个词在书库中的每一处出现逐条列出（书名、页码、前后文），可导出 Word 或 Excel。
- 逐字异文（0.26）：引文查证、稿件引文核对中“近似”的结果逐字对照原文，标出异字、脱字、衍字，可一键拷贝按原文改正的引文。
- 窗口（0.26）：各窗口记住位置和大小；⌘C ⌘V ⌘A ⌘Z 在输入框中可用，⌘F 跳到筛选框，⌘W 关闭。开机自动启动在 设置 › 通用 › 启动。
- 与 KongFolio 联动（0.25）：装了 KongFolio 后，⌥↩、引文查证的“打开到此处”、最近阅读都在 KongFolio 中打开到那一页并标出命中的字；
  KongFolio 的阅读进度也显示在 KongSeek 中。设置 › 通用 › PDF 阅读 中可选择阅读器，设置 › 更新 中可一键安装或更新 KongFolio。
- 后台任务（0.24）：建立索引、文字识别、生成可搜索 PDF、打包、引文核对、书库体检等进行时，菜单栏图标变成带圈的放大镜，
  菜单顶部列出进度，可查看或停止。
- 阅读进度与最近阅读（0.24）：阅读窗口记住每本 PDF 读到第几页，再打开时接着读；菜单栏图标 › 最近阅读 列出最近读过的书；
  文件清单显示“读到第 N 页 / 共 M 页”。
- 保存文件清单（0.24）：文件清单窗口“清单”菜单 › 保存为清单…，以后从“清单”菜单或 菜单栏图标 › 写作与引文 › 已保存的清单 打开。
- 废纸篓记录（0.24，菜单栏图标 › 整理文件 › 废纸篓记录…）：KongSeek 移到废纸篓的文件，三个月内可查原位置并一键放回原处。
- 书库体检（菜单栏图标 › 书库体检…）：列出打不开的 PDF、加密的 PDF、损坏的 EPUB、0 字节文件、没下载完的临时文件，以及有多个文件的同一本书。
- 两版讲义对比（菜单栏图标 › 两版讲义对比…，或幻灯片 / PDF / Word 上 ⌘K › 与另一版本比较…，或“查找重复”中版本旁的“对比”）：
  逐张（页、段）列出新增、删除、修改，修改处标出增删的行；可打开新版到该张。
- 生成可搜索的 PDF（PDF 上 ⌘K，或“查找扫描版 PDF”中每个文件旁的按钮）：另存一份，每页原样保留，识别出的文字以不可见方式放在原位置，
  “预览”等应用中可搜索、选中、拷贝；原文件不动。
- 整理新下载的电子书（有新下载时出现在菜单栏图标中）：把下载文件夹中网站长文件名的电子书改成短书名并移到电子书文件夹，先预览、可撤销、可忽略。
- 文件清单（菜单栏图标 › 文件清单…，或搜索结果上 ⌘K › 把全部结果放入文件清单）：把一个文件夹或一次搜索的结果列成表格，
  显示书名、作者、出版社、年份、格式、大小、阅读状态，可筛选、排序；对所选（或全部）一次拷贝参考文献表（按作者拼音排序）、
  导出书单（CSV，Excel 可直接打开）、设置阅读状态、移到废纸篓。
- 课程视图：⌘S 收藏搜索时可起名（如“《论语》导读”= `in:论语 ext:pptx,pdf,docx`），清空搜索框时按名字列出；收藏上按 ⌘K 可重命名、放入文件清单。
- 拷贝引文：全文命中后 ⌘K › “拷贝引文”，拷贝命中的整句和出处（电子书为带页码的 GB/T 7714 参考文献，其他文件为“《文件名》第 N 页/张”）。
- 阅读状态：⌘K › 阅读状态 › 待读 / 在读 / 精读 / 已读（访达标签，同一时间只有一个），搜索 `标签:在读` 等列出。
- 最近下载：菜单栏图标 › 最近下载，列出 7 天内从浏览器、邮件、隔空投送下载的文件，按住 ⌥ 改为在访达中显示。
- 状态与诊断…：索引、唤起、权限、文字识别、更新、Claude 工具、iCloud 未下载文件数一览，需要处理的项附有按钮。
- 拷贝为参考文献：电子书上 ⌘K › “拷贝为参考文献（GB/T 7714）”，按文件名（及 EPUB 自带的书目信息）生成
  `作者. 书名: 副题[M]. 出版地: 出版者, 年份.`，并提示缺哪些项；出版地若按出版社推定会注明。请以版权页为准核对。

## 剪贴板历史

默认关闭。按 ⌃⌥V（或菜单栏图标 › 剪贴板历史）打开窗口，点“启用剪贴板历史”，之后复制的文字、图片和文件会被记录。

| 操作 | 按键 |
| --- | --- |
| 粘贴到原来的应用 / 纯文本粘贴 / 仅拷贝 | ↩ / ⇧↩ / ⌘↩ |
| 整理后粘贴 / 预览整理效果 | ⌘J / ⌘E |
| 固定 / 删除 | ⌘P / ⌘⌫ |
| 拷贝图片中识别出的文字 | ⌘T |
| 送到 KongReview 摘录 | ⌘R |
| 更多操作 | ⌘K |

直接粘贴需要“辅助功能”权限（设置 › 剪贴板）。带机密标记的内容（如密码管理器复制的密码）不记录。

文本片段：剪贴板窗口中按 ⇥ 切换到片段，↩ 粘贴。片段可设关键词（如 `;lk`），在任何应用中输入关键词会自动替换为片段内容
（需要“输入监控”和“辅助功能”权限）。在 设置 › 片段 中编辑。

## 更新、备份与诊断

设置 › 更新：
- 检查更新 / 安装更新：从 GitHub 获取新代码，在本机测试、编译、校验签名后安装，KongSeek 自动重新打开；不满意可“回退到上一版”。
  默认启动后和每 6 小时自动检查一次，有新版本时菜单栏菜单顶部会提示。也可以继续双击 `构建并安装.command`。
- 安装 / 更新 KongFolio：从 GitHub 下载源码到 ~/Developer/kongfolio，在本机编译后替换“应用程序”中的 KongFolio。

设置 › 通用：
- 开机自动启动：开机登录后 KongSeek 自动在菜单栏待命。
- 导出 / 导入设置：设置、文本片段，以及书上页码、补全的书目、常用本、文件清单、阅读进度存为 `.kssettings` 文件，换机或备份用。
- 搜索历史：打开或显示过结果的搜索会被记下（最多 50 条），可关闭或清除。
- 导出诊断包：出问题时生成一个 zip 发给开发者。

## 其他

搜索框为空时列出最近用 KongSeek 打开过的文件和应用。命中的文字、拼音对应的汉字和缩写字母会以黄色标出。

连按 Control 需要“输入监控”权限：首次启动时系统会询问；也可以在“设置…”里点“授予‘输入监控’权限”，
在系统设置中打开 KongSeek 的开关，几秒内自动生效。

设置窗口（菜单栏图标 › 设置…）：唤起（快捷键、连按）、索引（文件夹、隐藏文件、匹配所在文件夹、压缩包、重建索引）、
文字识别、剪贴板、片段、网页搜索、通用（开机启动、PDF 阅读、导出设置、诊断）、更新（KongSeek 与 KongFolio）。

## 索引

- 默认索引主目录、iCloud 云盘、“应用程序”和系统应用；跳过 `~/Library`、`node_modules`、`.git`、`DerivedData`、废纸篓、
  隐藏文件和应用包内部。名为 `build`、`Library` 的普通文件夹照常收录。
- 索引存放在 `~/Library/Application Support/KongSeek/name-index.ksidx`。启动时直接载入，并从上次退出的位置补上期间的文件改动，
  不需要整盘重扫；运行时由 FSEvents 实时更新。
- 搜索引擎的速度、与 3.2 结果的一致性等测试数据见 `docs/引擎实测.md`。

## 结构

```
Sources/KongSeekCore         搜索引擎（无 AppKit，有单元测试）：名称索引、匹配与拼音、查询语法、索引文件、FSEvents
Sources/KongSeek             应用：菜单栏、全局快捷键、搜索窗口、预览
Sources/KongSeekText         文档正文读取（PDF、Word、文本）与 Spotlight 全文搜索，应用与 ks 共用
Sources/ks                   命令行搜索工具与 MCP 服务（读取应用保存的索引）
Sources/KongSeekLegacy32     KongFetch 3.2 的匹配与查询代码原样副本，只作测试和基准的对照
Sources/KongSeekTestSupport  测试与基准用的合成目录树
Sources/ksbench              性能基准：swift run -c release ksbench synth|new|legacy <目录>
Tests/                       XCTest
scripts/build-app.sh         命令行构建；--test 先跑测试，--install 安装
scripts/mac-test.sh          开发检查：编译全部目标、跑测试、可选基准，输出写入 .logs/
```
